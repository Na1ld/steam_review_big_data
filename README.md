# Прогнозування тональності відгуків користувачів Steam за характеристиками тексту та соціальною оцінкою

Проєкт із дисципліни **«Аналіз великих наборів даних»**, присвячений побудові масштабованого конвеєра обробки та машинного навчання на повному наборі відгуків платформи Steam (~6,41 млн записів) без використання підвибірок.

## Мета та питання дослідження
* **Дослідницьке питання:** Чи можна передбачити, чи є відгук гравця у Steam позитивним (рекомендованим), спираючись на ідентифікатор і назву гри, текст відгуку та кількість голосів за його корисність?
* **Цільова змінна:** `target` (перетворена з `review_score`: `1` — позитивний відгук, `0` — негативний відгук).
* **Практична цінність:** автоматизація моніторингу настроїв спільноти для розробників і видавців ігор, раннє виявлення масового невдоволення або «рев’ю-бомбінгу».

---

## Джерело даних
* **Назва:** [Steam Reviews (by Andrew MVD)](https://www.kaggle.com/datasets/andrewmvd/steam-reviews)
* **Ліцензія:** CC0: Public Domain
* **Обсяг сирих даних:** 6 417 106 рядків, 5 стовпців (~2.12 ГБ у форматі CSV).
* **Обсяг після очищення:** 4 618 780 унікальних валідних записів у стисненому форматі Apache Parquet (`zstd`).

### Опис змінних
| Стовпець | Тип у Parquet | Опис |
| :--- | :--- | :--- |
| `app_id` | `Int32` | Унікальний числовий ідентифікатор гри в каталозі Steam |
| `app_name` | `Categorical` | Назва гри (пропуски відновлено за довідником `app_id`) |
| `review_text` | `String` | Текст відгуку користувача |
| `review_votes` | `Int32` | Кількість голосів користувачів за корисність відгуку |
| `char_len` | `Int32` | Згенерована ознака: довжина відгуку в символах |
| `word_count` | `Int32` | Згенерована ознака: кількість слів у відгуку |
| `target` | `Int8` | Цільова змінна (`1` — рекомендує, `0` — не рекомендує) |

## Інструкція із запуску

### 1. Клонування репозиторію
```bash
git clone https://github.com/Na1ld/steam-reviews-big-data.git
cd steam-reviews-big-data
```

### 2. Завантаження даних
Завантажте файл `dataset.csv` зі сторінки [Kaggle Steam Reviews](https://www.kaggle.com/datasets/andrewmvd/steam-reviews) та помістіть його у папку `data/dataset.csv`.

### 3. Встановлення залежностей
Рекомендується використовувати менеджер пакетів `uv` або стандартне віртуальне середовище Python:

**Варіант А (через `uv`):**
```bash
uv venv
uv pip install -r requirements.txt
```

**Варіант Б (через стандартний `pip`):**
```bash
python -m venv .venv
# Активація для Windows (Git Bash):
source .venv/Scripts/activate
pip install -r requirements.txt
```

### 4. Послідовне виконання ноутбуків
Запустіть ноутбуки у суворому порядку:
1. `notebooks/01_data.ipynb` — формує очищений набір `data/steam_reviews_clean.parquet`.
2. `notebooks/02_analysis.ipynb` — будує статистичні розподіли та зберігає візуалізації у `report/figures/`.
3. `notebooks/03_models.ipynb` — навчає та оцінює моделі на відкладеній тестовій вибірці (20%).

## Технологічний стек та оптимізація
* **Polars & Apache Parquet (`zstd`):** читання повного CSV на 6,41 млн рядків займає **0.85 с**, а оптимізація типів даних (`downcasting`) зменшує обсяг у RAM та на диску.
* **Потокова векторизація (`HashingVectorizer` + `float32`):** дозволяє перетворити 4,61 млн текстів у розріджену матрицю ознак без переповнення 16 ГБ оперативної пам’яті.
* **Моделі машинного навчання:**
  * `DummyClassifier` (`most_frequent`) — базовий орієнтир;
  * `SGDClassifier` (`log_loss`) — лінійна модель із масштабуванням ознак;
  * `LightGBM` — градієнтний бустинг на деревах рішень.

## Попередні результати експериментів (на тестовій вибірці 20%)

| :--- | :---: | :---: | :---: |
| `DummyClassifier` (бейзлайн) | 0.5000 | 0.8173 | 0.8995 |
